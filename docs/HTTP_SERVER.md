# HTTP file server

## Current address

- Public base: `https://eternalfast.aplot.cloud/`
- Public manifest: `https://eternalfast.aplot.cloud/manifest.json`
- Internal address: `http://10.0.0.51/`
- Published directory: `/srv/eternal-launcher/files`
- NGINX site: `/etc/nginx/sites-available/eternal-launcher`

The launcher depends only on HTTP, not on NGINX. The compiled address lives in
`src/config/LauncherConfig.h`, in the `FileServerBaseUrl` constant.

## Mods and configs: just upload the file

Upload each `.jar` to `/srv/eternal-launcher/files/mods/` over SFTP. For configs,
keep the path Minecraft expects inside `/srv/eternal-launcher/files/config/`; for
example, Simple RPC's files go in `config/simple-rpc/`. The `eternal-manifest.timer`
service scans `mods/` and `config/` every 10 seconds and generates `manifest.json`
on its own, including size and SHA-256. Don't edit the JSON or compute hashes by
hand. The launcher reads the list again when you click **Jogar** (Play), downloads
new files and replaces files whose hash changed.

Wait a few seconds after an upload finishes for the manifest to be published.
Names with spaces or brackets are accepted. Files still being uploaded are not
listed. Mods removed from the server disappear from the manifest; on the next
**Jogar** click, the launcher deletes the local copies it had installed once the
sync finishes. Mods added by the player in the instance's `mods` folder are never
removed. Removed configs stop being downloaded on new installations; existing
config files are not deleted automatically.

To check the automation on the server:

```bash
systemctl status eternal-manifest.timer
systemctl status eternal-manifest.service
cat /srv/eternal-launcher/files/manifest.json
```

Files outside `mods/` and `config/` are kept in the manifest but are not discovered
automatically.

## Publishing with FileZilla

For the executable and its updates, follow [AutoUpdate and releases](AUTOUPDATE.md).
The launcher's signed manifest is published at `launcher/latest.json` and is not
generated by the mods timer.

Use SFTP, not unencrypted FTP:

```text
Protocol:    SFTP - SSH File Transfer Protocol
Host:        10.0.0.51
Port:        22
Destination: /srv/eternal-launcher/files
```

You don't need to upload `manifest.json`: it is generated on the server.
Credentials and passwords must never be saved in this repository.

## Administration

```bash
nginx -t
systemctl reload nginx
systemctl status nginx
tail -f /var/log/nginx/eternal-launcher.access.log
tail -f /var/log/nginx/eternal-launcher.error.log
```

## Security and next steps

- Create an SFTP account dedicated to publishing, without admin access.
- Rotate any admin credentials that have been shared.
- Keep public HTTPS and the `no-store` header on the manifests.
- Restrict the firewall to the networks and ports that are needed.
- The executable manifest is already signed; extend signing to the mod manifest.
- Implement safe removal of other files that leave `files`.
