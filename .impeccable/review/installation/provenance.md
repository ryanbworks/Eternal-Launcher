# Installation capture provenance

The seven installation-*.png production previews (checking, download, Forge,
error, cancelled, cancelling, compact) are generated by EternalLauncher.exe
--render-preview, using synthetic state. Native nickname text is drawn as Steve.
Normal captures are 1180 × 730; compact is 944 × 584. Other PNGs in this directory
are the existing main/settings/AutoUpdate previews emitted by the same command.

installation-live.png and installation-live-compact.png are PrintWindow client
captures of a visible test-owned Win32 host created by WindowPaintingTests.exe
--capture-installation. They use real native EDIT/BUTTON controls and synthetic
installation metrics; Steve is set in the test host only. The host performs Tab
and Enter assertions, then captures the client at 1180 × 730 and 944 × 584.
No network, authentication, game installation or game launch is performed by
that capture command. The test host is destroyed at the end.

docs/images/installation.png is copied from installation-download.png, with an
adjacent origin file. No new raster asset or AI-generated image was introduced.
