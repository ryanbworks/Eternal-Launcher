# Settings-entry performance captures — 2026-10-04

Generated by the production MainPage renderer in WindowPaintingTests
`--capture-motion .impeccable/review/navigation-performance`. Normal: 1180 × 730;
compact: 944 × 584. Settings uses WM_PRINTCLIENT for the parent, then WM_PRINT
for each visible child in explicitly mapped/clipped client coordinates, with real Win32 EDIT,
BUTTON and TRACKBAR controls. Other sequences use the production frame buffer
with synthetic Steve text. Time, host state, paths and values are synthetic.
No network, game launch, production credentials or global preference changes.

The first comparison matched all 36 earlier settings-entry PNGs exactly, but
inspection exposed a shared old fixture error: WM_PRINT/PRF_CHILDREN shifted
native children by the non-client origin, duplicating controls. The fixture now
maps each child explicitly; these final captures supersede that comparison.
Regression tests separately compare the cached form against current uncached
production drawing at both sizes, including edited values and keyboard focus.
Captures demonstrate composition, not physical compositor cadence.

Separate visible-host benchmarking measures warm render work and WM_PAINT
intervals; raw results are in benchmark.txt. The earlier motion GIF is re-encoded
with these corrected native settings frames. Motion timing and appearance remain
the same in production.
